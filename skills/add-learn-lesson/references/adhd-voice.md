# ADHD voice for Learn

The classroom is built for a tired, willing reader. Protect working memory.

## Shape

- **One step on screen.** The rest of the mountain stays folded.
- **Short sentences.** One idea per paragraph.
- **Verbs first.** Say what to do, then why, then the catch.
- **No quizzes.** Ticking a step is enough. Nothing grades them.
- **No streaks, XP, or expiry.** Progress waits. They can park.
- **No “you should already know.”** Define a term on first use, then use it.

## Prose

- About 80–120 words of body copy per step, not counting code.
- `why` is one sentence. It answers “why am I looking at this now?”
- Titles stay concrete: `Verify Turnstile with remoteIp null`, not `Best practices`.
- Commands and file paths in code blocks, never buried in a paragraph.
- Address overwhelm once, calmly: “You do not need to memorize this.”

## What never goes in a lesson

- Secrets, tokens, passwords, account ids, real cert ARNs
- “As we discussed” / chat UUIDs / internal traces
- Emoji in chrome or headings
- Fake APIs or trimmed quotes that change meaning
- A cliffhanger that requires the next lesson to make this step true

## Tone samples

Yes: “The Lambda is a thin door. It logs the method and path, then hands off.”

No: “Now that we’ve explored the fascinating world of serverless entrypoints, let’s dive in!”

Yes: “Park here. The next lesson sits Email next to Contact.Api.”

No: “🔥 Lesson complete! You’re on a 3-day streak.”
